# EdUHK Lacrosse

A central online hub for **The Education University of Hong Kong (EdUHK) Lacrosse Team**, providing team information, training resources, event updates, and ways for prospective players and supporters to get involved.

**Live site:** https://s1155582.github.io/EdUHK_Lacrosse/

## About

EdUHK Lacrosse is a student-led sports community that promotes lacrosse at EdUHK through regular training, friendly matches, competitions, and team-building activities. This website makes it easier for current members, new students, and external partners to find essential information about the team.

The project also reflects the team’s commitment to developing athletic skills, sportsmanship, leadership, and an inclusive sporting culture on campus.

## Features

- Team introduction and overview of EdUHK Lacrosse
- Training schedules, session information, and venue details
- Upcoming events, competitions, and team activities
- Resources for beginners and current players
- Photo gallery or media section
- Contact information and recruitment details
- Responsive layout for desktop and mobile users

## Getting Started

This is a static website hosted with **GitHub Pages**. No installation or backend setup is required to view the site.

### View the Website

Open the live site here:  
https://s1155582.github.io/EdUHK_Lacrosse/

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/s1155582/EdUHK_Lacrosse.git
   ```

2. Navigate to the project folder:

   ```bash
   cd EdUHK_Lacrosse
   ```

3. Open `index.html` in your browser, or use a local server such as:

   ```bash
   python -m http.server 8000
   ```

   Then visit:

   ```text
   http://localhost:8000
   ```
